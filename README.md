# 投标风险哨兵
https://tangyuxi-coder.github.io/bid-risk-sentinel/
> 不替你写标书，专替你排雷——废标雷、投诉雷、刑事雷。

全网招投标 AI 都在卷"写标书"，没有人做风险端。投标风险哨兵把最高人民法院法答网权威答疑、刑法与立案追诉标准、招标投标法与政府采购法体系做成**写死在代码里的规则引擎**：结论可追溯、可复核，不依赖大模型自由发挥。

**纯前端 · 零后端 · 零成本 · 数据不出浏览器** —— 打开网页就能用，标书等商业敏感信息永不离开你的电脑。

## 为什么不用大模型直接判断？

法律 AI 最大的信任问题是幻觉。本产品的核心工程决策是**确定性优先**：

- 所有定性判断由规则引擎（代码化的法条逻辑）完成，每条结论可追溯到法条原文和效力层级
- LLM 只做"从几百页文件里提取信息"这一件它擅长的事，且为可选层（用户自带 DeepSeek Key，仅存于本地浏览器）
- 法律检索不用 RAG：法律语境下"向量相似但含义相反"的法条是灾难，法言法语关键词直搜召回质量更高、成本为零

## 规则与数据来源

- 《中华人民共和国刑法》第 223/231/64 条
- 《最高人民检察院、公安部关于公安机关管辖的刑事案件立案追诉标准的规定（二）》（2022年修订）第 68 条
- 《中华人民共和国招标投标法》（2017修正）全文及其实施条例（2019修订）全文
- 《中华人民共和国政府采购法》（2014修正）及其实施条例（国务院令第658号）、《政府采购质疑和投诉办法》（财政部令第94号）
- 最高人民法院法答网精选答问（第二十四批）串通投标罪专题（人民法院报，2025-07-03）
- 法发〔2010〕22 号参照适用通知

## 本地开发

```bash
npm ci
npm run dev      # 开发预览（http://localhost:3000）
npm run build    # 构建到 dist/
```

技术栈：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui

## 部署（GitHub Pages）

仓库内置 `.github/workflows/deploy.yml`：push 到 `main` 分支即自动构建并部署。
首次使用需在仓库 Settings → Pages → Source 选择 **GitHub Actions**。
